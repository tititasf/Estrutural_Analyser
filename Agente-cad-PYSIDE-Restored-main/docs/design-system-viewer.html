P Princípios Visuais

P1 · Dark Professional
Background escuro industrial (#121212 base). Zero cores vibrantes em superfícies grandes. Zero branco puro como background.
P2 · Dados em Primeiro Lugar
Conteúdo técnico ocupa espaço dominante. Chrome da UI é visualmente recuado — menor, mais escuro, menos peso.
P3 · Hierarquia por Cor
Cor = Função. Ciano = interativo. Azul = ação primária. Verde/amarelo/vermelho = estado. Gold = excelência.
P4 · Feedback de Estado
Todo processo exibe estado visual. Nenhuma operação roda silenciosa. Áreas vazias usam EmptyStateWidget.
P5 · Densidade Informacional
Otimizado para 1920×1080+. Rows 20px, lista 24px, fontes 9–13px. Chrome vertical: TopBar 40px + FaseBar 22px + TabBar 32px = 94px overhead total.

7 Anti-Padrões

✕ Proibido
color: "#00d4ff" # hex literal inline
✓ Correto
color: Colors.ACCENT_PRIMARY
✕ Proibido
col.setFixedWidth(540) # coluna tab fixa
✓ Correto
col.setSizePolicy(Expanding, Expanding)
✕ Proibido
win = QMainWindow() # popup para feature
✓ Correto
win.setWindowFlags(Qt.Widget) # embed inline
✕ Proibido
# área vazia sem mensagem layout.addWidget(QWidget())
✓ Correto
from src.ui.theme import EmptyStateWidget layout.addWidget(EmptyStateWidget(...))
✕ Proibido
font-size: 14px # sem token Fonts.*
✓ Correto
font-size: {Fonts.SIZE_XXL}
✕ Proibido
background: white # paleta clara
✓ Correto
background: {Colors.BG_PANEL} # sempre dark
