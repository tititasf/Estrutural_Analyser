Guia de Interpretação de Pilares Especiais

O que é isso? Pilares especiais são aqueles com geometria não-retangular: seção em L, T, C, diagonal, chanfrado ou com entalhe. As regras de faces ABCD do gabarito padrão se aplicam, mas requerem atenção extra à geometria.

2. Casos de Interpretação

Caso 1 — Pilar em L — seção não-convexo

O pilar tem seção em L. As faces ABCD continuam sendo definidas pelo bounding box da seção (retângulo mínimo envolvente). A reentrância pode criar bolso onde uma laje encavalha.

  • Bounding box define A/B/C/D como para pilar retangular
  • A reentrância da seção L pode conter laje de outro vão
  • Checar se a laje está dentro ou fora do polígono real
  • Orientação (VERTICAL/HORIZONTAL) pelo bounding box: maior dimensão = longa
A = face longa oeste
B = face longa leste
C = face curta norte
D = face curta sul

Caso 2 — Pilar com entalhe — rebaixo em uma face

O pilar tem um recorte/entalhe em uma das faces. O vazio do entalhe pode conter uma laje ou ser nulo. A face A tem geometria complexa — parte da face pode ser viga e parte pode ser laje (ou nulo no entalhe).

  • Entalhe = recorte no polígono da seção
  • O rebaixo pode abrigar laje de altura diferente
  • Tratar como dois segmentos de face: acima e abaixo do entalhe
  • Consultar DXF original para medir o entalhe
A = parte laje + parte nulo (entalhe)

3. Regras para Pilares Especiais

Protocolo de análise
  1. Calcular o bounding box (retângulo mínimo envolvente) da seção
  2. Determinar orientação: VERTICAL se altura > largura do bbox, senão HORIZONTAL
  3. Aplicar regra ABCD do guia padrão sobre o bbox
  4. Verificar se a laje encontrada está dentro do polígono real (não só do bbox)
  5. Para entalhes: tratar o recorte como área que pode ter laje diferente ou nulo
Tipo especialDesafio principalSolução
Seção em L / T / C Reentrância atrai laje indevida Checar sobreposição com polígono real, não só bbox
Pilar diagonal Orientação ambígua Usar ângulo da maior dimensão para definir A/B
Com entalhe Face tem geometria dupla Dividir face em segmentos acima/abaixo do entalhe
Chanfrado Vértice recortado pode confundir vizinhança Usar bbox — ignorar chanfro para atribuição ABCD
